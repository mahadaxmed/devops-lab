# DevOps Practice Project

A simple frontend application designed for learning DevOps concepts including Git, GitHub, CI/CD, Docker, deployment, and server management.

## What This Project Is

This is a minimal Next.js application that displays a simple greeting message. It serves as a practice project to learn DevOps workflows without the complexity of a full application.

## How to Install Dependencies

```bash
npm install
```

## How to Run It

```bash
npm run dev
```

The application will be available at `http://localhost:3000`

## How to Build It

```bash
npm run build
```

The production-ready build will be created in the `.next` directory.
